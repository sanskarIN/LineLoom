# LineLoom v0.5.1 — Streaming Resilience Preview

**GitHub pre-release, not stable.** LineLoom is a free, Apache-2.0-licensed VS Code extension for local-first inline code completion with models independently installed in Ollama.

## What's new since v0.5.0

- **Bounded network streams:** an Ollama generation response now has a total transfer limit of **1 MB** and an event-count limit of **4,096 NDJSON events**, in addition to the existing 10,000-character generated-text cap.
- **Correctly handles big transport chunks:** a network read containing many small valid JSON events is processed event by event, rather than being mistakenly rejected as one oversized event. Individual incomplete event lines remain limited to 50,000 characters.
- **Stricter data validation:** rejects malformed streamed JSON events, including non-string `response` values, invalid `done` statuses and array events.
- **Stops at completion:** the parser honors the first terminal `done: true` marker instead of processing unrelated events that arrive afterward.
- **Expanded tests:** unit regressions cover excessive bytes, too many tiny events, valid large multi-event chunks, malformed events and trailing post-completion responses.
- **Preserved existing features:** nine editor language IDs, manual model selection, nested ignore-file privacy protection, explicit HTTPS remote-origin approval, source-context limits, and manual retry on empty completions.

There are no new permissions, automatic cloud-model downloads, external analytics or account requirements.

## Install / update

1. Use compatible VS Code (`^1.96.0`) and start your own Ollama server. Install the coding model you want independently; an optional example is `ollama pull qwen2.5-coder:1.5b`.
2. Download `LineLoom-0.5.1.vsix` from this release's GitHub Assets.
3. In VS Code choose **Extensions → … → Install from VSIX** or run `code --install-extension LineLoom-0.5.1.vsix`.
4. Open a trusted source workspace, then run **LineLoom: Check Ollama Connection** or **LineLoom: Select Model**.
5. Type within a supported source file or explicitly invoke **LineLoom: Trigger Completion**. Use **LineLoom: Manage Autocomplete Languages** to choose active language modes.
6. Verify the supplied SHA-256 file with `sha256sum -c LineLoom-0.5.1.sha256` where supported.

## Validation and limitations

The publication workflow runs `npm ci`, TypeScript checks, lint, unit tests, the bundled extension, a real VS Code extension-host integration suite using **mocked Ollama**, dependency security audit, VSIX archive integrity verification and checksum generation. CI separately tests Windows, macOS and Ubuntu.

**Remaining validation gaps:** useful suggestions from real Ollama models across all nine languages, CPU/GPU latency on real hardware, offline user setup, and manual VSIX installation/ghost-text acceptance on each operating system. The four latest language modes (Go, Java, C and C++) remain experimental. The extension does not implement content-based secret scanning or cross-file indexing; review generated code for correctness, privacy and licensing.

This is **not a stable v1.0.0 release**. No VS Code Marketplace or Open VSX publication is claimed.
