# LineLoom v1.2.5 — Reset Privacy Diagnostics (Development)

**Source merged into main on 2026-10-23; not a stable release or GitHub pre-release.** This is the next candidate after v1.2.4. No GitHub tag, Visual Studio Marketplace or Open VSX publication is authorized by this development plan.

## Implemented in main

- Add native Command Palette action **LineLoom: Reset Privacy Timing Statistics** (`lineloom.resetPrivacyTimings`) so users can clear only the local privacy eligibility timing counters without toggling diagnostics.
- The action calls the existing in-memory `resetEligibilityTimings()`; it does **not** reset autocomplete preferences, model selection, privacy ignore rules, Ollama connection or other completion performance counters.
- When performance diagnostics are explicitly enabled, the native **Session Activity** sidebar and **Quick Actions** menu also offer a keyboard-accessible **Reset Privacy Timing Statistics** action. When disabled, those context-sensitive entries are hidden; the Command Palette reset remains available.
- Refresh the Activity Bar view after a reset. Regression tests check the sidebar and Quick Actions' opt-in visibility, command ID, and accessible descriptions, as well as ensuring the reset command does not switch off the diagnostics setting.
- Asynchronous policy checks capture a reset epoch: metrics generated from checks started *before* a reset are discarded, so delayed completions cannot repopulate erased session counters.
- No paths, source text, ignore policies, prompts or model responses are stored or transmitted.
- Align `package.json`, `package-lock.json`, unit manifest tests and preview candidate CI with development version 1.2.5.
- Add checksum-pinned upgrade smoke from the now-published **v1.2.4 GitHub preview → v1.2.5 candidate**, preserving the earlier verified v1.2.0 stable and v1.2.3 preview upgrade baselines. All CLI profiles are disposable and use synthetic preferences.
- Add an integration regression requiring and executing the real extension command inside Linux VS Code's editor host, without a live Ollama server.
