# LineLoom v1.2.5 — Reset Privacy Diagnostics (Development)

**Unreleased; not a stable release or GitHub pre-release.** This is the next candidate after v1.2.4. No GitHub tag, Visual Studio Marketplace or Open VSX publication is authorized by this development plan.

## Implemented for review

- Add native Command Palette action **LineLoom: Reset Privacy Timing Statistics** (`lineloom.resetPrivacyTimings`) so users can clear only the local privacy eligibility timing counters without toggling diagnostics.
- The action calls the existing in-memory `resetEligibilityTimings()`; it does **not** reset autocomplete preferences, model selection, privacy ignore rules, Ollama connection or other completion performance counters.
- No paths, source text, ignore policies, prompts or model responses are stored or transmitted.
- Align `package.json`, `package-lock.json`, unit manifest tests and preview candidate CI with development version 1.2.5.
- Add an integration regression requiring and executing the real extension command inside Linux VS Code's editor host, without a live Ollama server.
