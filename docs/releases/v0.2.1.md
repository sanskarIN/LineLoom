# LineLoom v0.2.1 — Streaming & Cancellation Preview

**GitHub pre-release · Apache-2.0 · Not stable**

LineLoom is a privacy-first, free VS Code code-completion extension that uses Ollama models installed and operated by the user. Version 0.2.1 focuses on reliability and protecting source context during streaming and editor changes.

## What's changed from v0.2.0

- **Prompt cancellation:** streamed Ollama responses now respond to abort signals even when a server stops sending data. Stale network reads can terminate instead of waiting indefinitely for another chunk.
- **More accurate editor cancellation:** switching editors, moving the active cursor, changing the current document, or closing it invalidates previous requests and clears the short-lived suggestion cache.
- **Bounded model discovery:** the `/api/tags` model-list response is limited to 256 KB before JSON parsing, avoiding unlimited memory consumption from an unexpected server response.
- **Private errors:** untrusted model-server error messages are not copied verbatim into reported exceptions.
- **More regression tests:** cancellation of stalled streams, arbitrary UTF-8 boundaries, oversized streaming output, model discovery response limits and active-editor cancellation.
- Existing five supported language families are unchanged: **Python, JavaScript/JSX, TypeScript/TSX, Rust and Kotlin**. There are no additional cloud accounts, auto-downloaded model weights or subscriptions.

## Install or update

1. Use VS Code compatible with the extension engine `^1.96.0`, plus an installed and running Ollama instance.
2. Install your chosen Ollama coding model yourself; the optional example is `ollama pull qwen2.5-coder:1.5b`.
3. Download `LineLoom-0.2.1.vsix` from this GitHub release's Assets.
4. In VS Code, use **Extensions → More Actions (…) → Install from VSIX**, or run `code --install-extension LineLoom-0.2.1.vsix`.
5. Open a trusted workspace with a supported file; run **LineLoom: Check Ollama Connection** and **LineLoom: Select Model**. Try autocomplete or **LineLoom: Trigger Completion**.
6. Optionally verify the attached checksum via `sha256sum -c LineLoom-0.2.1.sha256` where available.

## Verification and known limitations

The publication workflow runs `npm ci`, strict TypeScript checking, ESLint, unit tests, build, a real VS Code Extension Development Host **with a simulated Ollama HTTP server**, a dependency security audit, VSIX packaging, ZIP integrity checks and checksum generation. CI separately checks Windows, Ubuntu and macOS.

**Not verified yet:** quality and acceptance of generated ghost text with actual Ollama models across all five languages, real offline operation on end-user hardware, representative CPU/GPU performance, or fresh manual VSIX installation on all platforms. There is still no cross-file indexing, nested `.gitignore` enforcement or content-based secret scanning. Always review generated code.

This is **not** a stable release. No Visual Studio Marketplace or Open VSX publication is asserted.
