# LineLoom v1.2.1 — GitHub Maintenance Pre-release

**Channel: GitHub pre-release and VS Code pre-release VSIX.** This build is intended for testing, not a fully manually validated stable update.

## Included changes

- **Stop Current Generation** from the Command Palette, Quick Actions and native Control Center cancels queued or in-flight completion and invalidates cached suggestions without disabling future automatic or manual triggering.
- Default sensitive path exclusions now cover Terraform state/variable files, env variants, cloud credential stores and **files within sensitive ancestor directories** such as `src/credentials/`, `src/.env.local/`, `src/secrets/` and `src/.dev.vars.preview/`. Both named and canonical paths remain subject to workspace trust and ignore rules.
- Ignore-file edits invalidate asynchronous permission checks and cached generations. Already-transmitted content cannot be retracted from a model server.
- Package identity and integrity checks, a disposable CLI installation test and a pinned published v1.2.0-to-v1.2.1 **stable-channel candidate** CLI upgrade regression are in CI. The release VSIX itself uses the actual VS Code **pre-release marker**.
- `npm run test:source-tree` verifies the project-owned TypeScript module/import inventory reachable from `src/extension.ts`. Source .ts files are intentionally bundled into `dist/extension.js` in the VSIX rather than shipped individually.

## Downloads

- `LineLoom-1.2.1.vsix` — VS Code pre-release package, publisher `SanskarCodes.lineloom`.
- `LineLoom-1.2.1.sha256` — checksum for the VSIX archive.

Install with **VS Code** via Extensions → ... → Install from VSIX. Do **not** open the package using the separate Visual Studio IDE installer.

## Manual QA outstanding

Real local Ollama generation quality/latency, actual watcher-event timing, cancellation during real model streaming, keyboard/screen-reader navigation, and upgrade behavior on physical Windows, macOS and Linux machines are **not verified** by mocked CI tests. No claims of manual acceptance are made. Treat this as a preview, use synthetic/disposable workspaces for testing, and report privacy concerns privately.

This GitHub release does **not** publish or update Visual Studio Marketplace or Open VSX. Existing GitHub v1.2.0 remains the latest **stable** version. See [v1.2.1 release issue](https://github.com/sanskarIN/LineLoom/issues/31) and [privacy documentation](../../PRIVACY.md).
