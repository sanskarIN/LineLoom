# LineLoom v0.6.0 — Editor Quick Actions Preview

**GitHub pre-release · Apache-2.0 · not stable**

LineLoom is a privacy-first, free VS Code extension that offers inline code suggestions using a user-installed Ollama model. Version 0.6.0 introduces faster, more accessible controls for everyday editor usage without adding an online service.

## What's new since v0.5.1

- **Click-to-control status bar:** clicking LineLoom opens a **Quick Actions** picker instead of directly opening diagnostics.
- **Automatic pause/manual fallback:** **Pause Automatic Suggestions** stops typing-triggered model inference while keeping **LineLoom: Trigger Completion** available. Resume from the same picker. The setting persists in VS Code.
- **Eight quick operations:** enable/disable, pause/resume automatic suggestions, manual completion, installed-model selection, language selection, connection check, diagnostics and settings.
- **Clearer state:** the status indicator reads **LineLoom Manual** when automatic suggestions are paused.
- **Privacy unchanged:** opening Quick Actions alone does not fetch models or transmit code. Endpoint-sensitive choices require deliberate selection; a non-loopback remote endpoint still requires explicitly approved HTTPS.
- **Validation:** unit tests cover action mapping, and mocked VS Code extension-host tests cover registration and manual completion while automatic requests are paused.

The nine registered language IDs remain Python, JavaScript/JSX, TypeScript/TSX, Rust, Kotlin, Go, Java, C and C++. The last four are experimental.

## Install or upgrade

1. Install compatible VS Code (extension engine `^1.96.0`), start Ollama, and install a coding model yourself. LineLoom does **not** download models automatically.
2. Download `LineLoom-0.6.0.vsix` from this GitHub release's assets.
3. In VS Code choose **Extensions → … → Install from VSIX** or use `code --install-extension LineLoom-0.6.0.vsix`.
4. Open a trusted workspace with a supported file, then click **LineLoom** in the status bar to access controls.
5. Choose **Check Ollama Connection** and **Select Model** when needed. Use **Pause Automatic Suggestions** for manual-only operation.
6. Optionally verify `LineLoom-0.6.0.sha256` via `sha256sum -c LineLoom-0.6.0.sha256` on a compatible shell.

## Verification and known limitations

The release workflow runs `npm ci`, TypeScript checking, lint, unit tests, bundling, a VS Code extension-host test with a **mock Ollama** server, a dependency security audit, VSIX ZIP integrity checks and checksum generation. Separate CI jobs check Windows, macOS and Ubuntu.

**Still unverified:** quality and latency of real Ollama suggestions across nine languages, completely offline operation on end-user machines, fresh manual VSIX installation/acceptance on all three operating systems and the visual Quick Actions picker in representative installations. LineLoom does not scan source contents for secrets or index unrelated source files. Review generated code.
