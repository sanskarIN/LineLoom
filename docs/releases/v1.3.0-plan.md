# LineLoom v1.3.0 — Stable candidate work plan (NOT released)

**Current publicly released GitHub stable: v1.2.0; latest public preview: v1.2.4 (at candidate creation).** The isolated source candidate now declares **v1.3.0**, built as a genuine stable-channel VSIX. Source version is not proof of a published release; GitHub release and the independently maintained VS Code Marketplace/Open VSX channels must be verified separately. Hands-on QA remains unperformed.

## Candidate feature scope

- [x] [Draft implementation PR #93](https://github.com/sanskarIN/LineLoom/pull/93): explicit, per-session opt-in selection of up to two tiny extra source files, reusable strict path/ignore checks, no indexing, bounded file read, recheck after inference and cache isolation.
- [x] [Privacy design RFC](../privacy/selected-context.md) and [manual acceptance checklist](../qa/v1.3.0-manual-acceptance.md) describe boundaries and non-goals.
- [x] Add upfront selection validation, stale-consent rejection, preflight privacy/size checks and synthetic post-inference source mutation and mid-request consent-revocation regressions. Automated validation is not human sign-off.
- [ ] Review source-level privacy proof and test harnesses, especially settings and policy races, editor changes, remote consent and denial paths.
- [ ] Complete actual local Ollama quality experiments including Qwen FIM-vs-reference prompt tradeoffs and performance budget.
- [ ] Improve accessible selection/clearing UI and diagnostics, without writing paths or snippets to telemetry.
- [ ] Consider additional accuracy, latency and sidebar improvements only after the first privacy-audited implementation is stable.

## Security and publication gates

- [x] Validate high-severity [MSAL Node advisory #79](https://github.com/sanskarIN/LineLoom/issues/79) mitigation: compatible older VSIX packager/Azure Identity range plus reproducible npm lockfile, full high-severity audit and production-only moderate audit. Four moderate dev-only npm audit findings require ongoing review.
- [ ] Complete or explicitly defer [v1.2.5 manual approval #60](https://github.com/sanskarIN/LineLoom/issues/60) with clear owner authorization.
- [ ] Cross-platform lint, typecheck, unit tests, source inventory and actual VS Code Linux mocked editor-host integration pass.
- [ ] Real-model, desktop OS, accessibility, slow/large/sensitive workspace and security QA passes; capture reproducible sanitized results.
- [ ] Candidate stable-channel VSIX plus isolated installation and upgrade verification pass for v1.3.0.
- [ ] GitHub stable release must use a separately guarded owner-authorized main-branch publisher workflow, with the same checks and VSIX/checksum artifacts. No npm package or marketplace update is implied.
- [ ] Release notes reflect *actual verified features and deployment status*, not merely a development branch or automated test outcome.

## Deferred beyond v1.3.0

Automatic dependency/AST graph discovery, whole-workspace scans, persistent indexes, multi-provider inference and remote code sync remain out of scope.
