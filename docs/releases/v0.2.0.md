# LineLoom v0.2.0 — Editor Experience Preview

**GitHub pre-release — not stable.** LineLoom remains a free, Apache-2.0-licensed VS Code inline autocomplete extension for user-provided Ollama models. This preview emphasizes editor responsiveness and test coverage rather than claiming new language or AI-model capabilities.

## Changes from v0.1.1

- **Cleaner suggestions:** remove common partial prefix echoes, normalise model line endings and NUL characters, preserve meaningful leading indentation, and bound displayed suggestion size.
- **Configurable maximum suggestion lines:** new `lineloom.maxSuggestionLines` setting (default 8, range 1–20). When multi-line completions are disabled, the limit is always one line.
- **Short-lived exact suggestion reuse:** a small in-memory eight-entry, approximately 15-second cache avoids repeated Ollama requests for identical document versions, cursor positions, settings, model, endpoint, and nearby code. Cache keys are SHA-256 digests of request context; results are not persisted to disk or logged. Changing extension settings or disabling the extension clears the cache.
- **Editor-level integration regression:** the mocked Ollama integration suite now opens a real VS Code workspace/editor, invokes the inline provider, verifies its inserted text and cache hit, and verifies that `.env` is denied. Model transport testing remains mocked.
- **Expanded unit tests:** more completion cleaning and cache TTL/eviction test cases.

LineLoom continues to support **Python, JavaScript/JSX, TypeScript/TSX, Rust, and Kotlin**. It requires VS Code matching `^1.96.0` and an Ollama instance plus an installed coding model.

## Installation / update

1. Install VS Code and Ollama for your platform, then start Ollama.
2. Install an Ollama coding model yourself if necessary, for example `ollama pull qwen2.5-coder:1.5b`. Nothing downloads automatically from LineLoom.
3. Download `LineLoom-0.2.0.vsix` from the Assets section of this pre-release.
4. In VS Code open **Extensions > … > Install from VSIX**, or run `code --install-extension LineLoom-0.2.0.vsix`.
5. Reload VS Code if necessary, open a trusted workspace, select the model, and try **LineLoom: Trigger Completion** in a supported source file. Optional: adjust **LineLoom: Max Suggestion Lines** in Settings.

A `LineLoom-0.2.0.sha256` checksum is provided; on supported systems verify it with `sha256sum -c LineLoom-0.2.0.sha256`.

## Validation and limitations

Before publishing this preview, the release workflow executes `npm ci`, TypeScript checks, linting, Vitest, bundled extension build, dependency security audit, and VS Code extension-host integration with a **mocked** local Ollama HTTP server. VSIX archive integrity is verified and a checksum is generated. Cross-platform CI also runs on Windows, Ubuntu, and macOS.

**Not yet verified:** live suggestion quality from a real installed Ollama model for each language, actual model CPU/GPU latency, full offline smoke testing, end-user manual installation on all three OSes, and accuracy/security of generated code. No repository-wide context, content-based secret scanning or full nested `.gitignore` evaluation is claimed. Cache contents are kept only in process memory; cached suggestions still require workspace/privacy checks.

**No Marketplace or Open VSX publication is claimed.** Stable v1.0.0 requires real-model and platform verification; this is a GitHub **pre-release**.
