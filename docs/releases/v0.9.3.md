# LineLoom v0.9.3 — GitHub Pages Website & Preview Distribution

**GitHub pre-release · MIT · publisher: SanskarCodes · local-first Ollama inline autocomplete**

## Changes since v0.9.2

- Added a dedicated, responsive **static LineLoom project website** under `site/`. Includes installation steps, transparent feature descriptions, supported languages, privacy and network behavior, common questions, GitHub release links, accessible navigation, and original SVG icons/social-preview artwork.
- Added the **GitHub Pages deployment workflow** using `actions/configure-pages`, `actions/upload-pages-artifact` and `actions/deploy-pages`. The site is expected at https://sanskarin.github.io/LineLoom/ once GitHub Pages is enabled with **Source: GitHub Actions**, and the deploy job and live URL are verified. Source code alone is not proof of a live website.
- Added Node.js static-site regression tests: release/version alignment, local asset existence, fragment links, responsive and reduced-motion styles, honest privacy/preview claims, and no invented registry listings. These run as part of `npm run check`, together with existing TypeScript/ESLint/unit/build verification.
- Excluded standalone site files from the VSIX with `.vscodeignore`, preserving a focused extension artifact.
- Preserved `SanskarCodes.lineloom` publisher identity, explicit VS Code `--pre-release` packaging, nine registered languages, local-first defaults and privacy safety gates; **no new model provider or account requirement**.

## Download and install

1. Download `LineLoom-0.9.3.vsix` and optionally `LineLoom-0.9.3.sha256` from this GitHub pre-release.
2. Use VS Code `^1.96.0`. Choose Extensions → ··· → **Install from VSIX**, or `code --install-extension LineLoom-0.9.3.vsix`.
3. Install and start Ollama independently; download a compatible model manually (example `ollama pull qwen2.5-coder:1.5b`).
4. Open a trusted supported-language workspace. In the Command Palette run **LineLoom: Quick Actions** and verify the connection/model, then request code suggestions.
5. Check the VSIX checksum with `sha256sum -c LineLoom-0.9.3.sha256` using a compatible shell.

## Verified automation and outstanding QA

The pre-release workflow requires `npm ci`, TypeScript, lint, unit tests, static-site tests, a bundle build, Linux VS Code extension-host integration using **mock Ollama**, dependency audit, `vsce --pre-release`, VSIX ZIP integrity verification and SHA-256 generation. CI also checks Windows and macOS.

The website is a GitHub Pages deployment, not a hosted inference service. Initial GitHub Pages enablement may need an authorized repository owner to choose **Settings → Pages → GitHub Actions**. Consult [deployment instructions](../github-pages.md).

**Still unverified for stable v1.0.0:** real model accuracy, offline onboarding on every platform, CPU/GPU inference benchmarks, manual ghost-text acceptance, per-language output quality and physical Windows/macOS/Linux smoke checks. Go, Java, C and C++ remain experimental.

GitHub pre-release does **not** automatically publish the VSIX to Visual Studio Marketplace or Open VSX. Publisher verification and external publication are separate operations.
