## Included capabilities

- Native LineLoom Activity Bar sidebar with completion, default/overridden
  models, enabled languages, active-editor context, privacy and connection status.
- Additional privacy-preserving in-memory completion engine status and counters:
  requests, suggestions, cancellations, cache hits, continuation reuse, empty
  results and failures. Average measured latency is shown only after the user
  enables performance diagnostics and a successful sample exists.
- Privacy-safe, categorical error messages for unavailable Ollama servers, missing models, timeouts, unauthorized requests and malformed/oversized responses, without exposing raw server error content.
- Model selection rejects duplicate, malformed, control-character-bearing and oversized model names returned from an untrusted Ollama endpoint; display is bounded to 512 entries. It also discards obsolete discovery results after endpoint/approval changes.
- Native inline suggestions via a configured Ollama model with manual/automatic
  triggering, multiline support, response filtering, cancellation and caching.
- Nine language IDs: Python, JavaScript (+JSX), TypeScript (+TSX), Rust, Kotlin,
  Go, Java, C, C++. The last four remain experimental. C# and Dart are
  **not implemented** and are not advertised as supported in this candidate.
- Workspace-trust restriction, path and ignore exclusions, blocked unapproved
  remote HTTPS inference, file-only document schemes and opt-in explicit remote
  approval. No built-in telemetry, remote account or cross-file indexing.

## Packaging and installation

**Install from this GitHub release:**

1. Download `LineLoom-1.2.0.vsix` and `LineLoom-1.2.0.sha256` from this release's assets.
2. Verify SHA-256 locally.
3. Open **VS Code → Extensions → … → Install from VSIX…**, not Visual Studio's
   separate VSIX Installer. Or use `code --install-extension LineLoom-1.2.0.vsix`.
4. Install Ollama and the selected coding model yourself. LineLoom never
   automatically installs models or starts sending source to remote servers.

dependency audit, packaged VSIX identity and **absence** of VS Code pre-release

from these checks.**
