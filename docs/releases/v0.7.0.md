# LineLoom v0.7.0 — Typed Suggestion Continuations Preview

**GitHub pre-release · Apache-2.0 · local-first VS Code inline autocomplete · not stable**

## What's new since v0.6.1

- **Continue as you type:** LineLoom can recognize when a developer types the first 1–32 characters of an already-offered suggestion, and propose only its still-missing tail. This uses an in-memory candidate rather than making another Ollama request.
- **Conservative context checks:** the optimization requires the same document, editor language, model and endpoint settings; precisely matching preceding/following code digests; one consecutive document edit; and a single valid cursor. The normal trusted-workspace and ignore rules still apply.
- **Short-lived, limited memory:** only one generated completion and metadata/hashes are stored for up to 12 seconds. Original source context is not retained in plaintext by the new continuation cache or persisted.
- **Manual stays manual:** invoking **LineLoom: Trigger Completion** still runs the usual model-backed completion path instead of forcing the cache.
- **Diagnostics:** the local diagnostics channel now includes an aggregate typed-continuation reuse counter.
- **Regression checks:** expanded unit coverage and a real VS Code extension-host test against a **mock Ollama HTTP server**, confirming that after one character is typed, the remaining suggestion appears without another model-generation call.

All nine registered editor language modes remain available: Python, JavaScript/JSX, TypeScript/TSX, Rust, Kotlin, Go, Java, C and C++ (the four most recently added remain experimental). Existing Quick Actions, manual-only mode, remote-HTTPS approval, redirect rejection, sensitive-file exclusion and bounded streaming remain.

## Install or upgrade

1. Install a VS Code version compatible with extension engine `^1.96.0` and start an independently installed Ollama server and coding model.
2. Download `LineLoom-0.7.0.vsix` from the Assets of this GitHub pre-release.
3. In VS Code choose **Extensions → … → Install from VSIX** or run `code --install-extension LineLoom-0.7.0.vsix`.
4. Open a **trusted** source workspace; use **LineLoom: Quick Actions → Check Ollama Connection** and **Select Model**.
5. Request a completion, then try typing the beginning of the ghost text. A matching one-step edit can let the provider propose the remainder with no extra inference request.
6. Where supported, verify the attached `LineLoom-0.7.0.sha256` using `sha256sum -c LineLoom-0.7.0.sha256`.

## Validation and limitations

The release workflow requires locked dependency installation, TypeScript typechecking, ESLint, Vitest unit tests, the extension bundle, VS Code extension-host integration with **mocked Ollama**, dependency audit, VSIX archive validation and checksum creation. Cross-platform CI separately checks Windows, macOS and Ubuntu.

**Not verified:** real Ollama generation quality, genuine human typing/ghost-text acceptance and latency benefits on end-user systems, fully offline installed-model setup or manual VSIX acceptance on every platform. The continuation optimization may intentionally fall back to inference for non-consecutive edits or long bounded context shifts. No new network services, data collection, cloud account or cross-file indexing is introduced. Review all generated code.

This is a **GitHub pre-release**, not a stable v1.0.0, and Marketplace/Open VSX publication is not claimed.
