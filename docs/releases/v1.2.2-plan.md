# LineLoom v1.2.2 — Settings Safety Development Candidate

**Status: under development, not tagged or published.** Intended for a future GitHub pre-release after the v1.2.1 preview is verified. A passing automated package job does not constitute a versioned release.

## Changes under development

- Normalize user-selected Ollama model names using the same bounded, control-character-free tag structure accepted during model discovery. Invalid or non-string default model settings yield an **unavailable model**, rather than throwing at `.trim()` or silently choosing a different model.
- Normalize optional per-language overrides using the same validator. Unknown or malformed overrides are discarded; supported overrides remain unchanged.
- Malformed Ollama endpoint settings remain **invalid** instead of silently defaulting to localhost.
- Normalize `keepAlive` to a bounded duration or the safe default `5m`.
- Invalid custom exclusion settings fail closed with an ignore-all pattern; they must never silently allow previously excluded documents.
- Add pure unit tests and source-tree coverage for all new TypeScript files. The CI candidate still checks a disposable v1.2.0-to-development upgrade but does **not** prove physical desktop upgrade behavior.
