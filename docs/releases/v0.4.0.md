# LineLoom v0.4.0 — Language Expansion Preview

**GitHub pre-release, not stable.** LineLoom is free, Apache-2.0-licensed and local-first. It uses coding models installed separately in Ollama, with no LineLoom account or telemetry.

## What's new

- **Four additional experimental languages:** Go, Java, C and C++ are now registered for native VS Code inline suggestions. They join Python, JavaScript/JSX, TypeScript/TSX, Rust and Kotlin, bringing supported editor language IDs to **nine**.
- **Language selection:** use **LineLoom: Manage Autocomplete Languages** in the Command Palette to choose precisely which languages can request completions.
- **Direct configuration:** the `lineloom.enabledLanguages` array has known-ID validation. An empty list disables all LineLoom completions; JSX/TSX follow JavaScript/TypeScript.
- **Language-aware prompts:** the four new languages include conservative language-specific guidance for generic Ollama models.
- **Regression testing:** added unit cases for language registration and opt-outs plus mocked VS Code integration checks for `.go`, `.java`, `.c`, and `.cpp`. Four example programs are committed for further manual testing.

New language support is **experimental**. Registration and mocked completions do not prove the quality of generated code from real local models.

## Install or upgrade

1. Install VS Code (engine `^1.96.0`) and Ollama. Start Ollama and install your own appropriately licensed coding model; for example `ollama pull qwen2.5-coder:1.5b`.
2. Download **LineLoom-0.4.0.vsix** from the release assets.
3. In VS Code, choose **Extensions → … → Install from VSIX** or use `code --install-extension LineLoom-0.4.0.vsix`.
4. Open a trusted folder with a supported source file; use **LineLoom: Check Ollama Connection** and **LineLoom: Select Model**.
5. Run **LineLoom: Manage Autocomplete Languages** to enable/disable individual languages; type code or choose **LineLoom: Trigger Completion**.
6. Optionally verify the attached `LineLoom-0.4.0.sha256` via `sha256sum -c LineLoom-0.4.0.sha256` where supported.

See the [language selection guide](https://github.com/sanskarIN/LineLoom/blob/main/docs/languages/README.md).

## Validation and known limitations

The pre-release workflow requires `npm ci`, TypeScript, ESLint, Vitest, extension bundle, a real VS Code extension-host test using **mocked Ollama**, dependency security audit, VSIX packaging, archive integrity verification and a SHA-256 checksum. Repository CI additionally checks Windows, Ubuntu and macOS.

**Unverified:** actual autocomplete usefulness across all nine languages using real models, end-to-end code acceptance on each operating system, CPU/GPU performance and offline operation on real end-user machines. LineLoom performs no content-based secret scanning and does not index unrelated project files. Treat model-generated code as untrusted until reviewed.

This release is a **GitHub pre-release only**, not stable v1.0.0 and not claimed as published to VS Code Marketplace or Open VSX.
