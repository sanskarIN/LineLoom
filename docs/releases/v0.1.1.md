# LineLoom v0.1.1 — Reliability & Privacy Preview

**GitHub pre-release — not stable.** LineLoom remains a free, Apache-2.0 licensed, privacy-first VS Code inline autocomplete extension for Ollama models installed separately by the user.

## Changes since v0.1.0

- **Stronger workspace privacy:** canonical symlink target checks prevent an in-workspace alias from sending code sourced outside the trusted workspace. Both the displayed path and the real target path must pass configured ignore rules and sensitive-path checks.
- **Conservative exclusion failures:** if an ignore file exists but is unreadable, completions are denied instead of bypassing its intended exclusions. Missing optional ignore files are treated normally.
- **Stale result prevention:** discard model responses after editor focus, cursor position, document version, trust or exclusion configuration changes.
- **More reliable setup:** installed-model discovery and model details requests have eight-second timeout signals rather than potentially waiting indefinitely.
- **Safer errors:** server HTTP error bodies are no longer echoed into error messages.
- **Regression tests:** added path-traversal/symlink tests and HTTP model-listing/error tests.

The five supported language families are **Python, JavaScript/JSX, TypeScript/TSX, Rust and Kotlin**. Core functionality remains local Ollama-powered inline suggestions, bounded context, configurable model parameters and native editor actions.

## How to upgrade

1. Install VS Code (compatible with extension engine `^1.96.0`) and Ollama for your platform.
2. Keep Ollama running; if needed, manually install a coding model: `ollama pull qwen2.5-coder:1.5b`. This is optional example model guidance, **not** an automatic download.
3. Download `LineLoom-0.1.1.vsix` from this GitHub release.
4. In VS Code use **Extensions → … → Install from VSIX**, or run `code --install-extension LineLoom-0.1.1.vsix`.
5. Restart/reload the extension host if necessary and run **LineLoom: Check Ollama Connection** and **LineLoom: Select Model**.
6. Open a supported file in a trusted workspace and type code or invoke **LineLoom: Trigger Completion**.

Verify the attached `LineLoom-0.1.1.sha256` with `sha256sum -c LineLoom-0.1.1.sha256` if your platform has sha256sum.

## Validation and limitations

The release workflow runs a reproducible dependency install, strict type checking, ESLint, unit tests, a mocked VS Code extension-host integration test, dependency audit, VSIX packaging and archive verification. Automated tests cover private-file rules and symlink target resolution on supported test hosts; Windows symlink creation in unit tests is skipped where privilege constraints would make it unreliable.

**Not yet verified:** an end-to-end real local Ollama completion on every language and platform, manual VSIX acceptance testing on actual Windows/macOS/Linux editors, model quality or offline operation on real systems, and representative CPU/GPU performance. There is no cross-file indexing, full nested `.gitignore` support or guaranteed credential-content detection. Treat generated code as untrusted and review it.

No Microsoft Marketplace or Open VSX publication is claimed. This is a **pre-release**, not a stable 1.0.0 build.
