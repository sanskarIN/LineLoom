## Scope

- Add a **privacy-safe, opt-in** timing summary for the two existing source-eligibility gates around model inference.
- `lineloom.performanceDiagnostics` controls collection (default **false**). No extra filesystem or model requests are made solely for timing.
- Count permits and denials; display last/average/recent p95/session-max latency in `LineLoom: Open Diagnostics`. The p95 is computed from a bounded, rolling **64-sample** in-memory window; average and max cover the current in-memory session.
- No path, ignore rule, source text, endpoint URL, model response, prompt, or per-document identifier enters the timing accumulator. Disabling performance diagnostics clears existing statistics.
- Do not represent these opt-in figures as actual editor-wide or Ollama latency; they measure eligibility checks only.
