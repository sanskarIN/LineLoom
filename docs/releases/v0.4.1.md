# LineLoom v0.4.1 — Editor Safety Maintenance Preview

**GitHub pre-release • not stable** · Apache-2.0 · VS Code compatible with `^1.96.0`

LineLoom is an open-source, local-first VS Code inline autocomplete extension for user-installed Ollama models. This maintenance preview focuses on preventing unintended requests and conflicting suggestions in everyday editing.

## Changes since v0.4.0

- **Stronger foreground checks:** before any local or explicitly approved remote inference request, LineLoom revalidates the exact active document, original document version and requested cursor position after its debounce and asynchronous privacy checks.
- **Safe selection behavior:** selected ranges and multiple active cursors no longer invoke the single-cursor inline provider.
- **Cooperation with IntelliSense:** automatic LineLoom suggestions defer when VS Code is currently presenting a selected standard completion. Manual trigger remains available when the editor has one empty selection.
- **Safer cache reuse:** exact-match cached results pass the same active-editor and cursor validation before being offered.
- **Regression coverage:** added unit tests for empty-selection/single-cursor requirements and integration tests with a simulated Ollama server, checking selected text, multiple cursors, IntelliSense collisions and moving the cursor during a debounce delay. The integration checks verify no additional model requests for these invalid states.
- **Documentation:** updated troubleshooting and development notes. The nine existing language IDs remain unchanged: Python, JavaScript/JSX, TypeScript/TSX, Rust, Kotlin, Go, Java, C and C++. The four new v0.4.0 languages remain experimental.

No additional telemetry, cloud accounts, model downloads or remote data services are introduced.

## Install or upgrade

1. Install VS Code and start Ollama. If you do not already have an installed coding model, an optional example is `ollama pull qwen2.5-coder:1.5b`. LineLoom never pulls weights automatically.
2. Download `LineLoom-0.4.1.vsix` from this GitHub release's Assets.
3. In VS Code use **Extensions → … → Install from VSIX** or run `code --install-extension LineLoom-0.4.1.vsix`.
4. Open a trusted folder in a supported language, then choose **LineLoom: Check Ollama Connection** or **LineLoom: Select Model**.
5. Trigger autocomplete with a **single empty editor selection** (no highlighted text or multiple cursors). Select enabled languages with **LineLoom: Manage Autocomplete Languages**.

The matching `LineLoom-0.4.1.sha256` can be used with `sha256sum -c LineLoom-0.4.1.sha256` on supported platforms.

## What the automated checks establish

The publication workflow requires reproducible `npm ci`, TypeScript checks, lint, unit tests, the extension bundle, VS Code extension-host integration against a **mocked Ollama HTTP server**, dependency audit, VSIX archive verification, and SHA-256 checksum generation. CI also runs checks on Windows, macOS and Ubuntu.

**Not independently tested yet:** real inference with installed Ollama models across all nine language IDs, complete offline/manual VSIX installation and editor acceptance on each operating system, real CPU/GPU latency and code quality. This extension is **not** a content-based secret scanner and does not support repository-wide indexing. Generated code needs review. The four recently added language modes are especially experimental.

LineLoom v0.4.1 is a **GitHub pre-release**, not stable v1.0.0, and publication to the VS Code Marketplace or Open VSX is not asserted.
