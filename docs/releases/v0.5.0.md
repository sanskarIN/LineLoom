# LineLoom v0.5.0 — Completion Quality & Efficiency Preview

**GitHub pre-release, not stable.** LineLoom is an Apache-2.0, local-first VS Code inline autocomplete extension. It uses models installed independently in Ollama and has no LineLoom account or telemetry.

## Changes since v0.4.1

- **Less repeated inference:** if Ollama produces an empty or unusable completion, identical automatic requests are suppressed for up to five seconds rather than re-running the same generation repeatedly.
- **Manual control remains:** explicitly using **LineLoom: Trigger Completion** bypasses the empty-result backoff, so developers can retry at any moment.
- **More reliable cleanup:** completion filtering now recognizes common FIM and chat boundary tokens and extracts code from a leading fenced block without inserting a model's explanation after that block.
- **Privacy-conscious state:** a small, memory-only backoff stores hashed exact request fingerprints rather than raw code or prompts. The entries are discarded when the provider resets; workspace-trust, file-ignore and editor checks still apply before every request.
- **More diagnostics:** aggregate empty-response and suppressed-retry counters appear in the LineLoom diagnostics channel.
- **Testing:** expanded pure unit tests and a real VS Code extension-host test with a **mock Ollama** server, verifying that automatic empty-result retries are skipped and manually triggered retries proceed.

LineLoom continues to register **nine language IDs**: Python, JavaScript/JSX, TypeScript/TSX, Rust, Kotlin, Go, Java, C and C++. Go, Java, C and C++ remain experimental.

## Installation / update

1. Use VS Code with extension engine support `^1.96.0` and a running Ollama instance with a coding model you installed yourself.
2. Download `LineLoom-0.5.0.vsix` from this release's Assets.
3. In VS Code choose **Extensions → … → Install from VSIX**, or run `code --install-extension LineLoom-0.5.0.vsix`.
4. Open a trusted workspace and a supported source file. Run **LineLoom: Check Ollama Connection** and **LineLoom: Select Model** to configure the local model. To select languages, run **LineLoom: Manage Autocomplete Languages**.
5. Type to request a completion. If it returns nothing, you can invoke **LineLoom: Trigger Completion** to retry manually.
6. Where supported, verify `LineLoom-0.5.0.sha256` with `sha256sum -c LineLoom-0.5.0.sha256`.

## Validation, security and limitations

The publication pipeline requires `npm ci`, TypeScript, ESLint, Vitest, extension build, a real VS Code extension-host integration run with **simulated Ollama responses**, dependency audit, VSIX archive inspection and SHA-256 generation. Cross-platform repository CI runs on Windows, macOS and Ubuntu.

**Not yet independently verified:** real-model ghost-text quality in all nine languages, CPU/GPU latency on real hardware, end-user offline operation or manual VSIX installation and acceptance across operating systems. The release does not add repository indexing or source-content secret scanning. Remote HTTPS endpoints still require explicit separate approval. Review generated code for safety, correctness and licensing.

This is a **GitHub pre-release**, not a stable v1.0.0 or VS Code Marketplace/Open VSX launch.
