# LineLoom v0.8.0 — Manual Responsiveness & MIT License Preview

**GitHub pre-release · MIT-licensed project-owned source · local-first VS Code + Ollama**

## What changed

- **MIT license:** LineLoom's current project-owned source distribution now uses MIT rather than Apache-2.0. The main `LICENSE`, npm metadata and contribution instructions are aligned. The licensing-history document preserves the distinction between historical Apache-2.0 tags, current source permissions and third-party dependencies/contributions.
- **Explicit requests run without typing debounce:** `LineLoom: Trigger Completion` no longer waits for `lineloom.debounceMs`, while retaining the existing editor, workspace, privacy and approved inference-endpoint protections.
- **Fewer unwanted automatic requests:** default behavior now avoids automatic suggestions when the cursor is immediately before an existing identifier character, including Unicode letters/digits, underscore and dollar sign.
- **User control:** disable `lineloom.suppressMidTokenAuto` in VS Code Settings if you prefer automatic completion while editing within identifiers. Manual triggering always remains available.
- **Tests:** extended pure unit tests, added a mocked VS Code extension-host regression for cursor-in-identifier requests, and a MIT license/npm metadata consistency check.
- **Unchanged:** nine registered language IDs (Python, JavaScript/JSX, TypeScript/TSX, Rust, Kotlin, Go, Java, C and C++; the latter four experimental), Ollama-first operation, native inline suggestions, typed continuation reuse, conservative nested file exclusions, explicit remote-HTTPS approval, redirect denial and no telemetry.

## Upgrade / install

1. Install VS Code compatible with `^1.96.0`, start Ollama, and independently install a compatible coding model.
2. Download `LineLoom-0.8.0.vsix` from GitHub release Assets.
3. Choose **Extensions → … → Install from VSIX** or use `code --install-extension LineLoom-0.8.0.vsix`.
4. Open a trusted source workspace and use **LineLoom: Quick Actions** to check the connection and select the model.
5. Try completion at the end of a line, within an existing identifier, and with **LineLoom: Trigger Completion**. Use `lineloom.suppressMidTokenAuto` to adjust your preference.
6. Verify the downloadable `LineLoom-0.8.0.sha256` with `sha256sum -c LineLoom-0.8.0.sha256` where supported.

## Validation, licensing and limitations

The release workflow requires `npm ci`, TypeScript, ESLint, Vitest, extension bundling, a real VS Code extension-host integration test against a **mocked Ollama HTTP server**, dependency security audit, VSIX archive integrity and SHA-256 generation. Separate CI runs on Windows, macOS and Ubuntu.

**This is still preview software:** real model-output quality, human editor ghost-text acceptance, offline installed-model setup and CPU/GPU timing across representative hardware require independent testing. Mid-token suppression is a character-boundary heuristic, not a full parser. Changing to MIT does not revoke existing Apache-2.0 grants for previously released versions or relicense any third-party code without appropriate rights.
