# LineLoom v0.3.0 — Privacy & Smart Completion Preview

**GitHub pre-release — not stable** · Apache-2.0 · VS Code `^1.96.0` · local-first Ollama

This preview improves how LineLoom protects source files and prepares inline completions. The five original language families remain **Python, JavaScript/JSX, TypeScript/TSX, Rust and Kotlin**.

## Changes since v0.2.1

- **Nested privacy rules:** `.gitignore` and `.lineloomignore` can now exclude files from subdirectories of the workspace, not just the root. Both workspace paths and canonical symlink targets must pass. Nested exclusions from independent files cannot be overridden with negation in another ignore source.
- **Bounded editor reads:** active-document context uses two limited editor ranges instead of copying the full contents of a large open file for each request.
- **Smarter automatic triggering:** new `lineloom.minAutoTriggerChars` setting, default 2 (range 0–32), avoids repeated inference on lines with too little non-whitespace input. The manually invoked **LineLoom: Trigger Completion** command bypasses this threshold.
- **Privacy-focused regression coverage:** unit tests verify nested precedence and sibling independence; a mocked VS Code extension-host test uses actual nested workspace ignore fixtures and checks that excluded files do not qualify.
- **Conservative limits:** ignore-policy file sizes are capped, traversals beyond 24 directory scopes fail closed, and a 20-second cache is invalidated by file watchers.

There is still no cross-file scanning or repository indexing, no LineLoom telemetry, no automatic model downloads, and no required cloud account.

## Install / upgrade

1. Install VS Code and start Ollama. If necessary, install a coding model yourself, for example `ollama pull qwen2.5-coder:1.5b`.
2. Download **LineLoom-0.3.0.vsix** from this pre-release's assets.
3. In VS Code choose **Extensions → … → Install from VSIX**, or run `code --install-extension LineLoom-0.3.0.vsix`.
4. Open a trusted workspace with a supported source file. Run **LineLoom: Check Ollama Connection**, **LineLoom: Select Model**, then trigger autocomplete.
5. Optional settings: `lineloom.minAutoTriggerChars`, `lineloom.maxSuggestionLines`, `lineloom.excludedPaths`; place `.lineloomignore` in directories with private content.

A matching **LineLoom-0.3.0.sha256** verification file is provided; verify on systems with `sha256sum -c LineLoom-0.3.0.sha256`.

## Verification and limitations

Publication requires a reproducible `npm ci`, TypeScript typecheck, ESLint, Vitest unit tests, build, a VS Code extension-host test with a **mock local Ollama server**, a dependency audit, VSIX ZIP integrity check and checksum generation. Cross-platform CI also tests Windows, Ubuntu and macOS.

**Not independently verified:** useful model-generated suggestions with an actual installed Ollama model for every language, real end-user installation and acceptance on all platforms, representative CPU/GPU latency, offline model behavior, or quality/security of generated code. LineLoom does not scan files for secret strings and supports only ignore policies on ancestor directories up to the stated scope limit. Remote HTTPS inference is disabled by default and requires explicit approval.

This is a **pre-release**, not stable v1.0.0, and is not claimed to be published on VS Code Marketplace or Open VSX.
