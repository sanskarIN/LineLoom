# LineLoom v0.9.4 — VS Code Installation & VSIX Verification Preview

**GitHub pre-release · MIT · Publisher: SanskarCodes · Requires VS Code 1.96+ and independently installed Ollama**

## Why this preview?

A user reported that double-clicking the v0.9.3 VSIX on Windows opened **Visual Studio VSIX Installer** and showed: “One or more extensions are for Visual Studio Code. Try installing them in Visual Studio Code.” That message comes from the **wrong installer**: the downloaded extension is for **Visual Studio Code**, not the full **Visual Studio IDE**. It does not by itself indicate a failed download, damaged VSIX, or incompatibility with VS Code.

## Changes since v0.9.3

- Published a new [step-by-step installation help page](https://sanskarin.github.io/LineLoom/install.html), covering Windows PowerShell and VS Code's built-in VSIX installation UI as well as macOS/Linux setup.
- Updated the homepage, README, publisher guide and troubleshooting documentation so users avoid file association mistakes.
- Added a **read-only VSIX verification script** that inspects ZIP structure and expected bundled extension files, confirms the packaged `SanskarCodes.lineloom` manifest identity/version matches the source, and rejects unexpectedly embedded dependencies, sensitive `.env` filenames and the standalone website.
- Both CI VSIX packaging and the GitHub preview release workflow now run the new archive verification before upload.
- Updated the manifest version/lockfile to `0.9.4` and pointed its homepage to the live GitHub Pages website.
- Preserved local-first Ollama completion, privacy controls, nine registered languages, MIT licensing, explicit `--pre-release` VSIX metadata and GitHub-only preview release policy.

## Download and install: **do not double-click on Windows**

1. Download `LineLoom-0.9.4.vsix` from the GitHub pre-release assets.
2. Open **Visual Studio Code** (not Visual Studio Community/Professional/Enterprise).
3. Press **Ctrl+Shift+X**, click **...** (Extensions menu), choose **Install from VSIX…**, and select the downloaded file.
4. Or in PowerShell, from the folder containing the file, run `code --install-extension .\\LineLoom-0.9.4.vsix` if your VS Code `code` CLI is configured.
5. Install/start Ollama and a coding model separately (example: `ollama pull qwen2.5-coder:1.5b`), open a trusted workspace, and run **LineLoom: Quick Actions**.

A genuine VS Code installation error should be reported with the **exact VS Code error message** (but no passwords, secrets, code snippets or personal paths). See the [troubleshooting guide](../troubleshooting/README.md).

## Verification and limitations

The release workflow requires a locked npm install, TypeScript, lint, unit tests, website checks, VS Code extension-host integration with a **mocked** Ollama endpoint, dependency audit, a pre-release-marked VSIX, read-only archive/manifest inspection, and SHA-256 checksum generation. GitHub CI checks Windows/macOS/Linux.

The verification script ensures the VSIX has the expected shape and publisher identity. It **does not** prove real installation or code-completion quality on each device. The stable v1.0.0 gate still requires manual VS Code installation tests, real Ollama CPU/GPU performance and model quality checks, and physical Windows/Linux/macOS testing. Go, Java, C and C++ remain experimental.

This is a **GitHub pre-release**, not a stable v1.0.0 release. Microsoft Visual Studio Marketplace and Open VSX require separate publisher-authorized uploads.
