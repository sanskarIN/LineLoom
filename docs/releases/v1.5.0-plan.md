# LineLoom v1.5.0 Stable — publisher-confirmed release gate (plan only)

**Status: BLOCKED / PLANNED (2026-11-18). No v1.5.0 tag, stable VSIX, Marketplace update, or Open VSX update has been published.** The target is the first stable release after the **confirmed and completed** Microsoft publisher transition from `SanskarCodes` toward `Sanskar`. Documentation alone is not confirmation.

## Non-negotiable entry conditions

- [ ] **Official Microsoft decision:** retain a written support confirmation of an authorized, workable Marketplace publisher reassignment or separately approved compliant alternative. Record which public extension ID and existing-install behavior Microsoft actually supports.
- [ ] **Migration performed and verified:** verify intended Microsoft publisher ownership, exact public listing identity, published version and installability in a clean VS Code profile. Verify prior-user update continuity where supported; otherwise publish explicit manual reinstall steps and known lost state. Do not assume a changed publisher ID preserves installations or reviews.
- [ ] **Safe legacy behavior:** keep the original `SanskarCodes.lineloom` listing until an approved transition and rollback path are verified. No deletion to evade extension-name collision; no simultaneous enabled copies with shared commands/settings.
- [ ] **Security gate:** no unresolved blocking high/critical release dependency findings (including [#297](https://github.com/sanskarIN/LineLoom/issues/297)) without a newly reviewed, documented owner risk decision. Verify package-lock and the exact packaged VSIX; the runtime-only audit is not sufficient to declare full CI green.
- [ ] **Technical gate:** clean locked install, full checks, cross-platform CI, extension-host and Ollama mock tests, preview/stable-channel manifest checks, SHA-256 receipts, archive parity where relevant, clean installs and actual upgrade/uninstall/reinstall smoke.
- [ ] **Human QA:** real local Ollama completions and latency, selected-context privacy consent/revocation, accessibility, keyboard, offline startup, Windows/macOS/Linux (or clearly recorded deferrals and owner acceptance). No unverified first-party model quality claim.
- [ ] **Release evidence:** changelog, stable notes, precise ID/version, installation guide, migration FAQ, rollback, verified destination links and source-free public acceptance summary.
- [ ] **Publication approval:** obtain an explicit **v1.5.0 Stable** owner authorization for the exact commit/tag and **each destination**. A support response alone is **not** approval to create tags, publish binaries, or change registries.

## Publish ordering — after every prerequisite passes

1. Freeze and test the reviewed `main` commit. Capture exact artifact hashes and publish/rollback instructions without embedding tokens, source content, file paths or user identities.
2. Resolve the Marketplace publisher transition with Microsoft **before** advertising `Sanskar.lineloom` as a public replacement. Verify the resulting identity directly rather than inferring it from publisher Owner access.
3. After separate owner authorization, publish the **stable-channel** GitHub v1.5.0 VSIX and independently verify public assets/checksums. Do not reuse v1.4.5 preview files as stable packages.
4. After separate Marketplace authorization, publish or complete the Marketplace change as Microsoft instructed; verify installation, public version, identity, update route and restore path. If the registry needs a different exact sequence, follow documented support guidance instead of guessing.
5. Update primary installation links only after confirming the corresponding public listing and package work. Preserve clear directions for users still on `SanskarCodes.lineloom`.
6. Follow the [Open VSX migration plan](../open-vsx-migration.md) as a **separate, owner-gated** registry operation. It may occur after Marketplace cutover; do not claim Open VSX v1.5.0 exists unless independently published and checked.

## Decision outcomes

| Microsoft outcome | v1.5.0 decision |
| --- | --- |
| Approved official reassignment; transfer completed and checks pass | Eligible for **separately owner-authorized** stable release |
| Supported but procedure incomplete or listing not verifiable | **BLOCKED**; retain existing stable and preview links |
| No reassignment possible; distinct extension name proposed | **BLOCKED** pending explicit owner naming/migration approval, new test and user notices |
| No written decision | **BLOCKED**; no implied automatic migration |
| Security/CI/manual release acceptance not satisfied | **BLOCKED**, regardless of publisher status |

## Do not confuse these identities or channels

`v1.4.5` is the **planned GitHub pre-release migration preparation** stage, while `v1.5.0` is the **planned stable** stage. GitHub Releases, Microsoft's Marketplace, Open VSX and the npm installer are separate. Package version, release channel, publisher ID and user update path must be verified independently; no first-party model weights are implied.
