# LineLoom v1.2.2 — Settings & Privacy Safety Pre-release

**GitHub pre-release only.** The attached VSIX uses VS Code's genuine **pre-release channel** metadata. This is not a stable release or a Visual Studio Marketplace/Open VSX update.

## What's improved

- **Safer model settings:** malformed or non-string default Ollama model tags now yield an unavailable model instead of throwing an exception. Global and per-language tags share the same bounded, control-character-free validation.
- **Endpoint integrity:** invalid/non-string endpoint settings remain invalid rather than silently selecting another inference endpoint.
- **Bounded keep-alive:** malformed keep-alive values use the normal safe default instead of sending arbitrary values to the model server.
- **Fail-closed privacy:** malformed custom path-exclusion settings become deny-all instead of silently dropping exclusions. The matcher has regression tests proving the fail-closed behavior.
- **Development integrity:** TypeScript source inventory, unit/site tests, lint/typecheck, mocked VS Code extension-host integration and dependency security checks run in CI. The release workflow validates package identity, true preview metadata, VSIX archive and checksum, plus a disposable VS Code CLI installation.
- **Stable → preview upgrade smoke:** the release workflow verifies the pinned checksum of the publicly released v1.2.0 stable VSIX, upgrades a disposable CLI profile to v1.2.2, and checks preservation of synthetic model, language, privacy and automatic-trigger settings.

## Artifacts and installation

- `LineLoom-1.2.2.vsix`: preview-channel VS Code extension for `SanskarCodes.lineloom`.
- `LineLoom-1.2.2.sha256`: checksum for the exact VSIX archive.

Download the files from this GitHub release. In **Visual Studio Code**, open Extensions, choose **… → Install from VSIX**, and select the VSIX. Use a separate test profile for preview testing. The Windows Visual Studio IDE VSIX Installer is not the correct installer.

## Manual QA outstanding

Physical Windows/macOS/Linux installs and upgrades, accessibility/screen-reader testing, real Ollama generation and cancellation, actual file-watcher timing, and hardware latency/model accuracy have **not** been independently verified. Automated and mocked tests do not prove those behaviors. Avoid using sensitive project data during preview evaluations.

The latest *stable* GitHub release remains [v1.2.0](https://github.com/sanskarIN/LineLoom/releases/tag/v1.2.0). The v1.2.1 preview remains independently available.
