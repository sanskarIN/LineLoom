# LineLoom v1.0.0 — First Stable GitHub Release

**Stable GitHub release · Publisher: SanskarCodes · MIT license · VS Code 1.96+**

LineLoom is a VS Code extension that offers context-aware inline suggestions from **your configured Ollama model**. It is local-first by default, does not require a LineLoom account or a hosted inference subscription, and has no built-in telemetry. This stable channel is the first major-version distribution milestone following the v0.9.x public previews.

## Core functionality

- Native VS Code inline suggestions with automatic and manual triggering, multiline output, configurable timeouts, and cancellation of stale requests.
- Ollama-compatible model selection with optional per-language overrides, model connection checks, editor status and Quick Actions.
- Language IDs: **Python, JavaScript, TypeScript, Rust and Kotlin** plus **experimental** Go, Java, C and C++.
- Privacy controls: trusted workspaces, sensitive/ignored-file exclusions, remote HTTPS endpoints **disabled by default** and explicit approval before sending context to a remote host.
- Bounded active-document context (no cross-file repository indexing), conservative output filtering, hashed suggestion caching, continuation, and optional aggregate timing diagnostics.
- Open-source development resources, GitHub Pages installation guide and test suites.

## Changes for v1.0.0

- Stable package version and matching npm lockfile; publisher remains **SanskarCodes**, so the extension ID is **SanskarCodes.lineloom**.
- Release packaging is **stable-channel VSIX**, with **no** `--pre-release` flag. Preview packaging remains available separately using `npm run package:preview`.
- CI verifies TypeScript, lint, unit tests, static website, Linux VS Code extension-host integration with a **mocked** Ollama server, and packaged VSIX installation via a clean VS Code CLI.
- GitHub release workflow additionally requires `npm audit --audit-level=high`, ZIP/manifest identity verification, version match and an attached SHA-256 checksum.
- Website, installation instructions and changelog updated for the stable channel. Visual Studio Marketplace and Open VSX require **separate authenticated publication** and are not automatically populated by this release.

## Download and install

1. **Recommended:** install from [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=SanskarCodes.lineloom) in VS Code or from [Open VSX](https://open-vsx.org/extension/SanskarCodes/lineloom) in an editor using that registry (verify publisher SanskarCodes). For manual/offline installation, download **`LineLoom-1.0.0.vsix`** and optionally **`LineLoom-1.0.0.sha256`** from GitHub.
2. In **Visual Studio Code** select **Extensions → ... → Install from VSIX...** and choose the VSIX. On Windows, do **not** double-click the file, because the full Visual Studio VSIX Installer is a different application.
3. From a terminal with VS Code's `code` command configured, an alternative is `code --install-extension LineLoom-1.0.0.vsix` in the download directory.
4. Install and start Ollama independently and obtain a compatible model, e.g. `ollama pull qwen2.5-coder:1.5b`.
5. In a trusted local source workspace, open **LineLoom: Quick Actions**, select your installed model, check the endpoint, then trigger a completion.

## What the checks establish — and what they do not

Automated tests validate a packaged VSIX that can be installed and listed by a **real VS Code CLI**, and test inline provider behavior against a **mock** Ollama HTTP server. These checks **do not** prove code accuracy or hands-on ghost-text acceptance using real models on every machine. One earlier user screenshot verified a v0.9.4 Windows install, **not** real completions with v1.0.0. No real CPU/GPU latency or complete offline QA measurements have been provided, so no such results are claimed. Report issues if you encounter editor or model problems.

**Known limitations:** Go, Java, C and C++ are experimental. No cross-file search or indexing. Sensitive-path rules are not full semantic secret detection. A user-approved external HTTPS endpoint receives bounded editor context and has its own privacy policy. Ollama/model availability, inference performance and output quality depend on local environment and chosen model.

The maintainer requested publishing the v1.0.0 stable tag despite the remaining **non-blocking** manual validation items. Follow the [QA evidence matrix](../qa/v0.9.5-readiness.md) to continue real-device testing; do not present unchecked cases as verified.

**Distribution status:** v1.0.0 is published on [GitHub Releases](https://github.com/sanskarIN/LineLoom/releases/tag/v1.0.0), [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=SanskarCodes.lineloom), and [Open VSX](https://open-vsx.org/extension/SanskarCodes/lineloom). Future version uploads must be performed separately for each destination; live-model QA remains ongoing.
