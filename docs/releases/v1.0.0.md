# LineLoom v1.0.0 — release candidate checklist

**Status: BLOCKED — do not tag or publish stable v1.0.0 yet.** The user will explicitly authorize the final phase separately. The v0.9.5 packaged CLI install smoke is not the same as real-model/editor verification. See [v0.9.5 manual QA matrix](../qa/v0.9.5-readiness.md).

Before publishing, record *actual* results for:

- [ ] npm reproducible install with checked-in lockfile
- [ ] strict TypeScript compile, ESLint, Vitest on supported CI runners
- [ ] unit and extension-host integration tests; mocked Ollama requests
- [ ] manual ghost-text display and acceptance for each of Python, JavaScript, TypeScript, Rust and Kotlin
- [ ] multiline completion and suffix-aware completion behavior
- [ ] stale cancellation, model missing, Ollama missing and timeout cases
- [ ] private-file denial and remote HTTPS approval
- [ ] offline use with previously installed Ollama/model
- [ ] Windows, Linux, macOS smoke checks
- [ ] real CPU-based and GPU-based model measurements (model tag, hardware, token count, latency)
- [ ] official packaging and fresh-install verification of `LineLoom-1.0.0.vsix`
- [ ] VSIX SHA-256 and contents/security inspection
- [ ] verified Marketplace publisher ID/authorization, if publishing externally

**Suggested verification commands:**
```sh
npm ci
npm run check
npm run package
code --install-extension LineLoom-1.0.0.vsix
```

The `code` CLI, Ollama and model must be installed separately. Record real results and hardware information here before checking any box. The current candidate is not equivalent to stable release readiness.
