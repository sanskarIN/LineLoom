# LineLoom v1.1.1 — Active Editor Sidebar Preview

**GitHub pre-release · Publisher: SanskarCodes · MIT · VS Code 1.96+**

This is an **opt-in test build**, following v1.1.0. The latest stable release
remains **v1.0.0** on [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=SanskarCodes.lineloom),
[Open VSX](https://open-vsx.org/extension/SanskarCodes/lineloom), and GitHub.
The planned **v1.2.0 stable release is not yet published**.

## What's new since the v1.1.0 preview

- **Active Editor** group in the LineLoom Activity Bar Control Center displays
  the current supported programming language, effective configured Ollama model
  (global default or per-language override), and preliminary completion status.
- Explains when suggestions are unavailable due to missing/unsupported editors,
  disabled languages, disabled autocomplete, restricted workspaces, invalid
  endpoints, disabled remote endpoints, or unapproved remote HTTPS inference.
- Recognizes JavaScript React (JSX) and TypeScript React (TSX) language IDs.
- Matches the inline completion provider's **file-only document scheme**:
  untitled/virtual editors are not incorrectly presented as eligible.
- Refreshes sidebar status when switching active editors.
- Adds explicit accessibility labels to native Tree View sections and rows,
  with expanded unit, static privacy-contract and extension-host coverage.
- All sidebar state is derived without reading document contents, filenames,
  file paths or endpoint URL strings, and without making model requests.

## How to try it

Download `LineLoom-1.1.1.vsix` from the **assets below**. Install in **Visual
Studio Code → Extensions → … → Install from VSIX…**. Windows users should not
double-click the VSIX in File Explorer: the Visual Studio VSIX Installer handles
a different extension format.

Or run `code --install-extension LineLoom-1.1.1.vsix` from the download directory.
Then choose the LineLoom icon in the Activity Bar or run
**LineLoom: Open Control Center** from the Command Palette.

Ollama and an appropriate coding model must be installed separately. Installing
the extension and opening the sidebar do not download or contact any model.

The companion `LineLoom-1.1.1.sha256` asset verifies VSIX integrity. The package
uses VS Code's **pre-release VSIX flag**, not the stable-channel flag.

## Important limitations

- **Completion eligibility is settings-level only:** an editor's displayed
  "Allowed by settings" does **not** bypass sensitive file, ignore-rule, or
  other request-time privacy gates. File permissions are enforced immediately
  before inference by the completion engine.
- Real Ollama model quality and CPU/GPU latency are not independently measured;
  manual VS Code UI, accessibility, workspace trust, and cross-platform user
  acceptance remain pending. No invented performance results are reported.
- Go, Java, C and C++ integration remains experimental. Cross-file repository
  indexing is not implemented. No built-in telemetry.
- Remote HTTPS endpoints require an explicit configuration opt-in and approval;
  loopback remains the default, and UI rendering does not contact the server.
- **This GitHub pre-release is not automatically published** to Microsoft
  Marketplace or Open VSX. Their stable v1.0.0 installation remains supported.
