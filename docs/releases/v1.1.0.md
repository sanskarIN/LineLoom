# LineLoom v1.1.0 — Sidebar Preview

**GitHub pre-release · Publisher: SanskarCodes · MIT · VS Code 1.96+**

This is an opt-in test build of the next LineLoom release. The previously published
**v1.0.0 remains the recommended stable channel** on the Visual Studio Marketplace
and Open VSX. This release does not automatically publish to either registry.

## New in this preview

- **Native VS Code Activity Bar Control Center:** discoverable LineLoom sidebar built
  with a native Tree View instead of a webview.
- **Completion controls:** enable/disable suggestions, pause automatic inference,
  trigger a manual suggestion and open the existing Quick Actions menu.
- **Model & language controls:** view configured model and override counts and invoke
  the existing approved model/language selectors.
- **Privacy & connection display:** see workspace trust and endpoint status by
  category. The sidebar never exposes the endpoint URL, editor source, prompts or
  file paths, and opening or refreshing it does not query Ollama.
- **Session activity:** aggregate request/suggestion/failure counters and a
  shortcut to the existing privacy-preserving diagnostics.
- **Publisher settings fix:** both Open Settings and the Setup Guide now target
  `SanskarCodes.lineloom`, not the old GitHub-owner-based identifier.
- Additional unit, integration, manifest, VSIX icon packaging and documentation
  checks for the sidebar.

## Download and install

Download `LineLoom-1.1.0.vsix` from this GitHub release's assets, then:

1. Open **Visual Studio Code → Extensions → … → Install from VSIX…**
2. Select the downloaded `.vsix`; do **not** double-click it in Windows Explorer
   (that may invoke Visual Studio's incompatible VSIX Installer).
3. Restart/reload the extension host if prompted; use the new **LineLoom** Activity
   Bar icon, or **LineLoom: Open Control Center** in the Command Palette.
4. Independently install and start Ollama and an appropriate local coding model;
   no model download occurs when LineLoom is installed or the sidebar opens.

For CLI installation: `code --install-extension LineLoom-1.1.0.vsix`.
The companion `LineLoom-1.1.0.sha256` is a checksum for download verification.

## Security and known limitations

- Remote HTTPS endpoints remain **off by default**, requiring explicit opt-in
  and origin approval. Local loopback is the default.
- Inline completions remain restricted by workspace trust, ignore rules,
  sensitive-file exclusions and active-editor checks.
- No cross-file repository indexing and no built-in telemetry.
- Tests with mocked Ollama, typechecking, lint, website verification, CI host
  checks and package-install smoke tests **are not a substitute** for real model
  acceptance, manual sidebar accessibility checks or CPU/GPU latency benchmarks.
- Go, Java, C and C++ language support remains experimental.
- Existing v1.0.0 stable packages at Visual Studio Marketplace and Open VSX
  remain independent of this GitHub-only preview. Do not claim these registries
  have v1.1.0 until their public listings verify it.
