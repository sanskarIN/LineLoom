# LineLoom v0.9.5 — VS Code Installation Smoke & Stable Readiness Preview

**GitHub pre-release only · Publisher: SanskarCodes · MIT · Local-first code completion using Ollama**

## Why another preview?

The v0.9.4 user screenshot confirms LineLoom was installed and enabled in **Visual Studio Code** on Windows. The previous VSIX Installer dialog was Windows opening the downloaded VS Code package with the *different* full Visual Studio application. Installation alone does **not** confirm that real Ollama inference, accepted ghost text and privacy denial cases have worked.

This release adds stronger automated **packaged-extension** validation while keeping the final stable release blocked until actual user testing.

## Changes since v0.9.4

- Add a real, isolated **VS Code CLI installation smoke test** in `scripts/smoke-install-vsix.mjs`. After archive validation, CI installs the VSIX using a clean downloaded VS Code and checks that `SanskarCodes.lineloom` appears at the exact version. The test profile is disposable and does not access personal workspaces or run models.
- Run the same packaged install smoke before GitHub publishes this pre-release. Existing Windows/macOS/Linux CI, Linux extension-host testing against *mocked* Ollama, privacy unit tests, security audit, archive identity validation, release checksums and pre-release flags remain in place.
- Update project website, installation page, README, changelog and publisher guides to v0.9.5.
- Add an explicit [manual QA evidence matrix](../qa/v0.9.5-readiness.md) for real Rust/Python/JavaScript/TypeScript/Kotlin suggestions, editor accept behavior, lost Ollama connection, privacy boundaries, offline behavior and physical Windows/macOS/Linux testing.
- Preserve existing completion behavior; there is no new cloud service, mandatory account, model download, telemetry, or automatic Marketplace/Open VSX publication.

## Install the preview

1. Download `LineLoom-0.9.5.vsix` from this release, plus `LineLoom-0.9.5.sha256` to verify the download if desired.
2. In **Visual Studio Code** (not Visual Studio Community), open **Extensions → … → Install from VSIX…** and choose the file. On Windows, **do not double-click** `.vsix` in File Explorer.
3. Or from the folder containing the VSIX, run `code --install-extension LineLoom-0.9.5.vsix` if the `code` CLI is installed.
4. Start independently installed Ollama, install a compatible coding model if needed (for example `ollama pull qwen2.5-coder:1.5b`), then use **LineLoom: Quick Actions** to select it.
5. Test with a trusted scratch Rust/Python file. Use **LineLoom: Trigger Completion**, observe ghost text, and check actual acceptance.

## Known limitations and release gate

**This is NOT stable v1.0.0.** A successful headless CLI installation and a mocked HTTP response are not equivalent to manual editor keystrokes, model accuracy, practical inference latency, or complete cross-platform acceptance. At least one screenshot verifies an earlier v0.9.4 install but not real suggestions. Real CPU/GPU measurements and all required manual cases are not yet established.

Go, Java, C and C++ remain experimental. No cross-file indexing. Source context is restricted by trust and file exclusion rules. Remote HTTPS inference can send snippets to an explicitly approved external endpoint. Do not assume the extension detects all secrets in source content.

The stable v1.0.0 release and **both** external registry uploads (Visual Studio Marketplace and Open VSX) are reserved for a later, explicit user-approved final-release stage. GitHub's preview workflow **does not** upload to those registries.
