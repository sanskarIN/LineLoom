# LineLoom v0.1.0 — Initial Preview

**Pre-release** · Apache-2.0 · Windows, Linux and macOS with supported VS Code and Ollama versions

LineLoom is a free, open-source, privacy-first VS Code inline-code-completion extension powered by a user-provided Ollama runtime and compatible coding model. This is an early preview for real-world testing, not a stable v1.0.0 release.

## Included

- Native VS Code inline ghost-text completion and manual completion command.
- Five initial language families: Python, JavaScript (including JSX), TypeScript (including TSX), Rust and Kotlin.
- Ollama streaming generation and installed-model selection; default suggestion is `qwen2.5-coder:1.5b`, which must be downloaded separately.
- Configurable model, endpoint, context budget, output tokens, timeout, multi-line mode and automatic triggering.
- Cancellation, stale-result filtering and completion cleanup.
- No LineLoom account or telemetry. Reads bounded nearby text from active documents in trusted local workspaces; filters sensitive paths. Remote HTTPS inference is disabled by default and requires confirmation.
- Native status indicator, diagnostics, setup guide, privacy policy and contributor documentation.

## Installation

1. Install VS Code and Ollama compatible with your OS.
2. Start Ollama and manually install a coding model, for example: `ollama pull qwen2.5-coder:1.5b`.
3. Download `LineLoom-0.1.0.vsix` below and open VS Code **Extensions > … > Install from VSIX** (or run `code --install-extension LineLoom-0.1.0.vsix`).
4. Open a trusted folder with a supported language file, then run **LineLoom: Check Ollama Connection** and **LineLoom: Select Model**.
5. Begin typing, or choose **LineLoom: Trigger Completion** from the Command Palette.

All model downloads are initiated by the user. No bundled AI weights or cloud subscription is required.

## What is verified and what is not

The repository contains unit tests for context, filtering, language registry, endpoint security, ignore precedence and streamed Ollama responses, plus a mocked VS Code extension-host integration suite. The release packaging job independently runs `npm ci`, static checks, linting, unit tests, integration tests, dependency audit and VSIX packaging before publication.

**Preview limitations:** automated registration and mocked inference are not proof of useful output from a real locally installed model on each language. No verified end-to-end ghost-text acceptance test across operating systems, real CPU/GPU latency benchmarks, guaranteed offline behavior or automatic correction of erroneous code is claimed. Cross-file context is not implemented; nested `.gitignore` files and source-content secret scanning are not covered. The output is untrusted code that the user should review before using.

## Integrity and support

A `.sha256` checksum file is attached alongside the VSIX. Verify it before installing (e.g., `sha256sum -c LineLoom-0.1.0.sha256` on systems with sha256sum).
