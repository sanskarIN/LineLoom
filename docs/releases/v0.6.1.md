# LineLoom v0.6.1 — Ollama Redirect Safety Preview

**GitHub pre-release, not stable** · Apache-2.0 · local-first VS Code inline autocomplete

LineLoom v0.6.1 closes a network privacy gap. Node's HTTP `fetch` normally follows redirects, which could otherwise forward editor context to a different host after an allowed endpoint responds with a 3xx status.

## Changes since v0.6.0

- **Reject unintended HTTP redirects:** `/api/generate`, `/api/tags` and `/api/show` explicitly use `redirect: "error"`. Ollama endpoints can no longer redirect the extension's requests to another origin automatically.
- **Respect approved endpoints:** inference still requires a trusted workspace, allowed file path and approved configured origin; only the explicitly configured destination may receive source context from LineLoom's fetch client.
- **Regression coverage:** added tests for all three HTTP routes and a test with two actual local HTTP servers: one sends a 307 redirect to the other, and the receiving server observes zero requests.
- **Documentation:** updated privacy, architecture, troubleshooting, README and changelog to explain rejected redirects and remaining network assumptions.

The update retains nine editor language IDs (Python, JavaScript/JSX, TypeScript/TSX, Rust, Kotlin, Go, Java, C and C++), Quick Actions, manual-only mode, bounded streaming, source exclusions and existing settings. No telemetry, cloud services or automatic model downloads are added.

## Install / upgrade

1. Install compatible VS Code (`^1.96.0`) and start Ollama with a coding model you installed yourself.
2. Download `LineLoom-0.6.1.vsix` from this GitHub pre-release's Assets.
3. In VS Code open **Extensions → … → Install from VSIX**, or use `code --install-extension LineLoom-0.6.1.vsix`.
4. Open a trusted source workspace, then use **LineLoom: Quick Actions** to check Ollama and choose a model.
5. Configure the **direct Ollama origin** rather than a forwarding URL; remote HTTPS inference still requires explicit approval.
6. Optionally verify the supplied `LineLoom-0.6.1.sha256` via `sha256sum -c LineLoom-0.6.1.sha256`.

## Automated verification and remaining limitations

Publication requires `npm ci`, TypeScript typechecking, ESLint, Vitest unit tests, the bundled extension, VS Code extension-host integration against a **mock local Ollama server**, dependency audit, VSIX ZIP verification and SHA-256 checksum generation. Repository CI additionally verifies Windows, macOS and Ubuntu.

**Limits:** rejecting redirects does not guarantee that an approved server or network proxy cannot store or relay submitted context; users must trust configured inference infrastructure. Code generated by installed models has not been independently verified for all nine languages. Offline/manual VSIX installation checks, representative CPU/GPU latency and actual editor acceptance remain outstanding. LineLoom is not a content-aware secret scanner or cross-file code index.

This is **not stable v1.0.0** and is not claimed to be listed on VS Code Marketplace or Open VSX.
