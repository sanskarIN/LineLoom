# LineLoom v0.9.2 — Marketplace Identity & Preview Packaging

**GitHub pre-release only · Publisher ID: SanskarCodes · MIT license · local-first VS Code code completion**

## What changed since v0.9.1

- **Publisher identity:** The extension publisher in `package.json` is now `SanskarCodes`, matching the user's Microsoft Visual Studio Marketplace publisher account. The extension identifier to use across registries is `SanskarCodes.lineloom`, while the GitHub repository remains `sanskarIN/LineLoom`.
- **Pre-release VSIX:** the default `npm run package` script and GitHub pre-release workflow now use the VS Code packaging tool's **`--pre-release`** flag. A GitHub pre-release label alone does not mark a VSIX as a Marketplace pre-release.
- **Reproducibility:** synchronized package and lockfile at `0.9.2`, plus a test guarding publisher identity, version consistency and pre-release packaging commands.
- **Automated verification:** CI on Windows/macOS/Linux, Linux VS Code extension-host tests using a **mocked** Ollama server, VSIX integrity and SHA-256 checksums, and a pre-release-only GitHub workflow with explicit duplicate-tag protection.
- **Publishing documentation:** separate manual Marketplace/Open VSX onboarding instructions, accurate claims policy, and outstanding stable-release QA gates.
- **No changes to inference semantics:** existing nine registered languages, Ollama configuration, model switching, privacy gates, caching, Quick Actions, typed continuation, and remote endpoint consent are retained.

## Download and install

1. Download `LineLoom-0.9.2.vsix` from this GitHub pre-release when the asset is published, plus the accompanying checksum file if desired.
2. Open compatible VS Code (`^1.96.0`) and choose **Extensions -> ... -> Install from VSIX**, or run `code --install-extension LineLoom-0.9.2.vsix`.
3. Install Ollama and a coding model **independently**, for example `ollama pull qwen2.5-coder:1.5b`; start the Ollama service.
4. Open a trusted source workspace, use **LineLoom: Quick Actions** to check the endpoint and model, and test suggestions with **LineLoom: Trigger Completion**.
5. Verify the file hash with `sha256sum -c LineLoom-0.9.2.sha256` on a compatible shell.

## Scope and limitations

This GitHub pre-release contains a **pre-release-marked** VSIX intended for user-controlled testing and subsequent registry uploads. **It does not itself publish LineLoom to the Microsoft Marketplace or Open VSX.** Both registries require authorized publisher operations and validation. See [publishing guide](../publishing.md).

The automated VS Code extension-host suite uses synthetic fixtures and a mocked inference server. Actual model quality, CPU/GPU inference latency, fully offline first-run setup, manual ghost-text acceptance, and hands-on testing of every OS/language remain unverified. Go, Java, C and C++ are experimental. Remote HTTPS inference can send allowed editor snippets to an approved external endpoint. There is no telemetry or cross-file source indexing.

This is **not** stable v1.0.0. The [stable gate](v1.0.0.md) remains blocked.
