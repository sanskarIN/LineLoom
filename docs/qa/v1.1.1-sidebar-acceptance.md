# LineLoom sidebar usability and privacy acceptance — v1.1.1 development

This is a manual test matrix, **not evidence that the tests have passed**.
The v1.1.0 GitHub pre-release remains the last published preview.
Automated unit, extension-host and package checks run in GitHub Actions,
but real user interaction and real Ollama quality still require actual testing.

## Developer checks

Run `npm ci && npm run check`, then `npm run test:integration` in the
supported VS Code extension-host environment. Observe exact CI run links
and record genuine platform/model results before checking off any
manual scenario.

The Active Editor section intentionally inspects only the VS Code
language identifier and extension settings. It never checks the file
path against ignore rules while rendering, reads the code, or connects
to Ollama. "Allowed by settings" **does not** mean a particular file
is cleared for inference: ignore and privacy rules remain enforced by
the completion engine on every request.

Do not promote v1.1.1 to stable based only on this list or mocked tests.
Track broader stable readiness in
[issue #21](https://github.com/sanskarIN/LineLoom/issues/21).
