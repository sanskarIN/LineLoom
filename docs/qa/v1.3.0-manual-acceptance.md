# LineLoom v1.3.0 manual stable candidate acceptance

**NOT RUN.** This checklist is not proof of validation; do not mark items complete without dated, sanitized evidence, reviewer, operating system, editor version and model identity. Do not upload source, prompts, credentials, or private paths to GitHub.

## Installer and general regression
- [ ] Confirm v1.2.5 / issue #60 gates are resolved or deliberately deferred with owner review.
- [ ] Ensure the `npm audit --audit-level=high` dependency security gate #79 passes with supported upstream dependencies.
- [ ] Independent Windows/macOS/Linux fresh VSIX installation, upgrades from published v1.2.0 stable and latest published preview, settings preservation.
- [ ] Compare actual default single-file completion, native sidebar, model selection, cancellation and manual/automatic triggers across supported languages.
- [ ] Verify no new account, telemetry, automatic model download, or filesystem crawl.

## Explicit related-file context
- [ ] Setting OFF: prove with filesystem/network inspection that no additional source is read or sent, even with a stale selected-file list.
- [ ] Setting ON with nothing chosen: no additional reads. Select two small allowed files using keyboard-only Command Palette and review explicit disclosure.
- [ ] Check a third selection is rejected (not silently added); switching editor and resetting/revoking settings clears consent.
- [ ] Test ignored paths from root and nested policy, .env/secret names, symlinks, outside-workspace and untrusted workspaces; all fail closed without model dispatch.
- [ ] Test 2,048-byte file bound, invalid UTF-8, binary/NUL, file deletion, file updates during a held model response, and cancellation during policy reads.
- [ ] Verify remote HTTPS approval independently warns about extra related snippets; revoke consent while request is pending. Do not test with actual secrets.
- [ ] Ensure diagnostics and output channels show only counts/aggregates, never file paths or selected source.
- [ ] Benchmark local Ollama quality, latency and memory with/without references (especially Qwen FIM fallback).
- [ ] Check screen reader label, disclosure modal focus and selection error feedback across Windows/macOS/Linux.

## Release checks
- [ ] All PR, main and versioned publisher workflows pass with no failed security gates.
- [ ] Build signed/verified stable-channel VSIX without `--pre-release`; inspect manifest publisher, version and installed behavior.
- [ ] Publish GitHub stable only after explicit owner authorization. Treat Visual Studio Marketplace and Open VSX as independent, separately authorized actions.
- [ ] Update website/README/changelog with verified public versions, checksum links and known QA limitations *after* publication.
