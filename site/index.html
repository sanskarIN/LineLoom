KNOW WHERE YOUR CODE GOES

Local-first doesn't mean guesswork.

LineLoom submits bounded context from the active document to your configured Ollama-compatible endpoint. On loopback, requests stay on your computer's networking stack. If you approve a remote HTTPS endpoint, the snippets travel to that server and are governed by its policies.

LineLoom has no built-in telemetry or automatic repository indexing. It excludes sensitive paths, but it does not provide comprehensive content-level secret detection. Review your settings before using confidential code.

GOOD TO KNOW

Frequently asked questions.

Is LineLoom free?

Yes. The extension source is released under the MIT License. Ollama and individual downloaded models have separate licenses and hardware requirements.

Does it need internet access?

After independently installing Ollama, a compatible model, and the extension, loopback inference can work without internet access. Fully offline setup and behavior across platforms have not yet been manually validated for stable release.

Is this stable software?

v1.0.0 is a GitHub stable release. Automated testing and a clean VS Code CLI install are verified. Actual model quality and hands-on acceptance across platforms are not independently certified.

Is LineLoom on VS Code Marketplace or Open VSX?

Yes, LineLoom v1.0.0 is published on Visual Studio Marketplace under publisher SanskarCodes. Open VSX publication has not yet been verified and requires a separate namespace claim and upload. The GitHub stable VSIX remains available as an alternative.

What about cross-file or repository-wide context?

Cross-file retrieval/indexing is not implemented in this release. LineLoom currently uses bounded context from the active trusted-workspace document.
