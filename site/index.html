OPEN DEVELOPMENT · NOT A RELEASE

Measuring code completion, responsibly.

The main branch contains optional, local-only model research tools. These are not part of the published v1.3.0 stable extension and do not mean a LineLoom Code checkpoint is available.

Original synthetic probes

Eight reviewable insert-at-cursor cases each for Rust, C, C++, Python and TypeScript. Strict string matching is not proof that generated code compiles or helps developers.

Source-free diagnostics

The v9 evaluation protocol reports exact-match, limited syntax checks, lexical warnings, latency and optional Ollama token counts without retaining generated source.

Developers can voluntarily compare two separately installed Ollama models on the same public fixtures and prompt mode. No hosted inference or automatic model downloads.

KNOW WHERE YOUR CODE GOES

Local-first doesn't mean guesswork.

LineLoom submits bounded active-document context to your configured Ollama-compatible endpoint. In v1.3.0, you may additionally opt in and explicitly select up to two tiny related source files; these can enter prompts only after user confirmation and privacy checks. On loopback, requests stay on your computer's networking stack. If you approve a remote HTTPS endpoint, the snippets travel to that server and are governed by its policies.

LineLoom has no built-in telemetry or automatic repository indexing. It excludes sensitive paths, but it does not provide comprehensive content-level secret detection. Review your settings before using confidential code.

GOOD TO KNOW

Frequently asked questions.

Is LineLoom free?

Yes. The extension source is released under the MIT License. Ollama and individual downloaded models have separate licenses and hardware requirements.

Does it need internet access?

After independently installing Ollama, a compatible model, and the extension, loopback inference can work without internet access. Fully offline setup and behavior across platforms have not yet been manually validated for stable release.

Is this stable software?

v1.3.0 is published as a GitHub stable release, with cross-platform automated checks, simulated Ollama editor-host testing and isolated VS Code CLI installation/upgrade checks passed. Real Ollama quality, physical desktop keyboard/accessibility and hands-on OS testing are NOT RUN and are disclosed in the release notes. Marketplace and Open VSX are independently distributed.

Is LineLoom on VS Code Marketplace or Open VSX?

Yes. LineLoom was first published as v1.0.0 on Visual Studio Marketplace. Open VSX Registry now serves Open VSX v1.3.0 Stable, confirmed publicly downloadable as latest with a verified namespace on 2026-10-25. Both use publisher SanskarCodes. Check the separate Marketplace listing for its current version. The GitHub stable VSIX is available as another option.

What about cross-file or repository-wide context?

Starting in GitHub stable v1.3.0, lineloom.crossFileContext can be explicitly enabled to select at most two supported same-workspace source files of up to 2,048 bytes each. Each file must pass ignore/privacy checks, and the user must confirm the local/approved-remote Ollama disclosure. The feature is off by default, has no workspace scanning, and does not implement automatic repository-wide indexing. See the privacy design and limitations.
