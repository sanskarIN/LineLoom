LINELOOM HELP / GITHUB STABLE v1.3.0

Install the extension.
In the right editor.

Latest GitHub stable: v1.3.0. Download LineLoom-1.3.0.vsix and its SHA-256 checksum from the public GitHub stable release. This version adds default-off, explicitly selected related-file context. Cross-platform CI and isolated VSIX upgrade checks passed; real Ollama performance, physical desktop/privacy and accessibility acceptance remain NOT RUN. The older v1.1.1 pre-release remains available. Open VSX serves v1.2.0 as last independently verified here, while Visual Studio Marketplace has a separate release schedule.

Latest GitHub testing preview: v1.3.1 (not stable). View the verified pre-release, download LineLoom-1.3.1.vsix and the SHA-256 checksum. This preview adds native sidebar contextual actions, explicit active-model/connection/file-privacy checks and completion safety hardening. Its true VS Code pre-release channel, checksum, mocked editor tests and pinned v1.3.0 stable-to-preview upgrade passed. Real-model performance, physical platform and screen-reader QA remain NOT RUN. Test with synthetic files in a disposable VS Code profile; Marketplace and Open VSX are not updated by GitHub.

LineLoom has a listing on Visual Studio Marketplace, and v1.2.0 Stable is published on Open VSX Registry. Choose the registry your editor supports. The GitHub v1.3.0 .vsix download is an extension archive, not a Windows executable; do not double-click it in File Explorer.

Recommended — Install from VS Code Marketplace

  1. Open Visual Studio Code and press Ctrl + Shift + X (Windows/Linux) or open the Extensions view on macOS.
  2. Search for LineLoom and verify the publisher is SanskarCodes.
  3. Click Install. Alternatively, open LineLoom on the VS Code Marketplace.
  4. Start your independently installed Ollama model and use LineLoom: Quick Actions to check the connection.
code --install-extension SanskarCodes.lineloom

Open VSX Registry — compatible editors

  1. Open your editor's Extensions view. Make sure it uses the Open VSX Registry as its extension source.
  2. Search for LineLoom, verify the namespace/publisher SanskarCodes, and choose Install.
  3. Or open LineLoom v1.2.0 on Open VSX to view the public stable extension listing and its download.
  4. Run LineLoom: Quick Actions to select a locally installed Ollama coding model after installation.

The Open VSX v1.2.0 Stable package is publicly downloadable; the public registry API reports verified: true for the namespace (checked 2026-10-20). The extension uses the same identifier SanskarCodes.lineloom.

Optional package manager installer — GitHub Packages

Published separately: @sanskarin/lineloom-cli@0.1.0 is an npm-format command-line installer. It verifies the SHA-256 of published GitHub VSIX files, choosing stable v1.2.0 by default or v1.2.4 only when --preview is given. It has not been updated for the new GitHub v1.3.0 stable release; use the verified v1.3.0 VSIX above for the new features. It is not a new extension release and is not published to npmjs.com.

Requires Node.js 22+, a supported editor command on PATH and authenticated read access to npm.pkg.github.com. Configure your npm package credentials privately; never paste tokens into public files or shell history. See the package manager installation guide for GitHub registry authentication.

npm config set @sanskarin:registry https://npm.pkg.github.com
npm install --global @sanskarin/lineloom-cli
lineloom install --dry-run

The CLI never automatically installs an extension when the npm package is installed. To install after verifying a dry run, explicitly run lineloom install. Hands-on installation on real Windows, macOS and Linux editors remains a separate QA step.

Got “One or more extensions are for Visual Studio Code”?

You opened LineLoom using the Visual Studio VSIX Installer (for the full Visual Studio IDE), rather than VS Code. This error usually means the download already succeeded; it does not prove the archive is broken. Close that installer and follow the VS Code steps below.

Windows 11 — manual GitHub VSIX installation

  1. Download LineLoom-1.3.0.vsix from GitHub release assets (save it normally).
  2. Launch Visual Studio Code, not Visual Studio Community, Enterprise, or VSIX Installer.
  3. Press Ctrl + Shift + X to open the Extensions view.
  4. Click the three dots (…) in the Extensions view, select Install from VSIX…, then choose the downloaded file.
  5. Confirm LineLoom appears under installed extensions. Start independently installed Ollama and use LineLoom: Quick Actions to choose a model.

PowerShell alternative

Run this command from your Downloads folder if the code command is available in your terminal:

code --install-extension .\LineLoom-1.3.0.vsix

Otherwise, use the built-in Extensions menu described above. You do not need to change your Windows file associations.

macOS and Linux

  1. Download LineLoom-1.3.0.vsix from the GitHub stable release.
  2. Open Visual Studio Code and choose Extensions → … → Install from VSIX….
  3. Optionally, when the code CLI is installed and your shell is in the download directory, run:
code --install-extension ./LineLoom-1.3.0.vsix

If installation still fails

  • Check the actual app: select Help → About in VS Code. Full Visual Studio and VS Code are different applications.
  • Verify the file ends in .vsix and was obtained from the official GitHub release. A checksum asset is included there.
  • Check your VS Code version meets the manifest requirement of 1.96.0 or later (compatible stable versions).
  • If the code command isn't recognized, use the UI method. On macOS, you may first need to install the code shell command from the VS Code Command Palette.
  • If VS Code reports an extension error, copy its exact text—without personal information—and open a GitHub issue. VSIX packaging tests alone cannot verify every machine.
