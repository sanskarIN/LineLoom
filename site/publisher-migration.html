LINELOOM / PUBLISHER TRANSITION

Moving to Sanskar.

v1.4.3 GitHub migration preview available. The current, already published extension ID is SanskarCodes.lineloom. The planned new ID is Sanskar.lineloom. They are different VS Code extensions, not an automatic in-place update. No new Marketplace or Open VSX listing is claimed live by this page.

Before you download

Continue using the currently verified VS Code Marketplace listing or Open VSX listing for stable v1.3.0. The published v1.4.3 GitHub pre-release has separate LineLoom-1.4.3-SanskarCodes.vsix and LineLoom-1.4.3-Sanskar.vsix packages, each with independently verified legacy and new-publisher SHA-256 checksums. This is a GitHub pre-release, not an update to either extension registry.

Publishing under the new ID cannot transfer installs, reviews, extension-private storage or publisher ownership. The maintainer will verify both new listings independently before directing stable users to them.

Move safely between publishers

  1. Note or back up your current lineloom.* VS Code settings, including local model, language overrides and excluded paths.
  2. Download the Sanskar preview VSIX and its SHA-256 checksum from the verified v1.4.3 GitHub release, then check the digest.
  3. In VS Code's Extensions view, uninstall the old SanskarCodes.lineloom extension and reload the editor. Do not leave both enabled because they share commands and configuration keys.
  4. Choose Extensions → … → Install from VSIX…, open LineLoom-1.4.3-Sanskar.vsix, and reload if requested.
  5. Recheck your privacy exclusions, local Ollama model and remote endpoint consent. Existing user settings may survive, but extension-private data and approvals do not automatically transfer.
code --uninstall-extension SanskarCodes.lineloom
code --install-extension ./LineLoom-1.4.3-Sanskar.vsix

Use these commands after downloading and verifying the published package. A VSIX must be installed inside VS Code, not with the separate Visual Studio VSIX Installer.

Prefer to remain on the old publisher?

Keep SanskarCodes.lineloom. For the latest independently verified stable build, use GitHub v1.3.0 stable. The new namespace is optional while this preview is being validated. For maintainer publishing instructions, see the full migration checklist.
